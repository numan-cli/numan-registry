First time here? Set up Numan and install a package

Install Numan from GitHub Releases or follow the platform installation guide. Put Nushell on PATH, then run:

numan init
numan registry sync
nu --version

Enter your Nu version below. Open a package for its install commands and upstream usage documentation. Installation only downloads, verifies and locks the package. Use the activation command when offered; open a new Nu session to use module autoloads. Some modules, scripts and completion packages are install-only: Numan does not activate or execute them.

After installing, run numan list to inspect installed packages and numan doctor --scan for read-only diagnostics.
